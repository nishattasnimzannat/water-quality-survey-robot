# Autonomous Multi-Point Water Quality Survey Robot

An autonomous robotic system designed to collect water-quality data from multiple points in a water body.

## 📌 Project Overview

The Autonomous Multi-Point Water Quality Survey Robot is a mobile robotic platform developed to automate the process of surveying water quality at multiple locations.

The robot is designed to navigate between predefined points and collect water-quality measurements using onboard sensors. The collected data can be used to analyze variations in water conditions across different locations.

## 🎯 Objectives

- Automate water-quality surveying at multiple points
- Reduce the need for manual water sampling
- Collect measurements from different locations
- Demonstrate autonomous robotic navigation
- Integrate sensors, microcontrollers, and motor control into a single system

## ⚙️ Main Features

- Autonomous movement between survey points
- Multi-point water-quality data collection
- Sensor-based measurement
- Motorized robotic platform
- Microcontroller-based control system
- Real-time/recorded sensor readings

## 💻 Software

The robot is programmed using Arduino-compatible code.

The source code can be found in:

`src/robot_code.ino`

## 🤖 How It Works

1. The robot is powered on and initialized.
2. The sensors and motors are configured.
3. The robot navigates toward the designated survey points.
4. Water-quality parameters are measured using the onboard sensors.
5. Measurements are collected from multiple locations.
6. The collected data can be analyzed to compare water quality across survey points.
